# blocks-generation-loader

## Why

Пользователь хочет видеть Blocks вместо Swirl во время подбора музыки.

## What Changes

- Заменить индикатор на `Blocks` из уже установленного `loading-dev` с размером 48 px.
- Сохранить таймер, этапы и превью треков.

## Non-goals

- Не менять API генерации или другие индикаторы в Mini App.
