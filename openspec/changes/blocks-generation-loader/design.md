# Design

`GenerationStatus` импортирует `Blocks` вместо `Swirl`. Индикатор остаётся декоративным для скринридера; доступный статус передаётся текстом и этапами. После просмотра пользователь попросил уменьшить индикатор с 48 до 24 px, чтобы он был соразмерен строке. Отступ у индикатора убран, чтобы он помещался рядом со строкой на узком экране. Новых зависимостей нет.
