# Design

`GenerationStatus` импортирует `Blocks` вместо `Swirl`. Индикатор остаётся декоративным для скринридера; доступный статус передаётся текстом и этапами. Размер 48 px задан согласно примеру пользователя. Отступ у индикатора убран, чтобы он помещался рядом со строкой на узком экране. Новых зависимостей нет.
