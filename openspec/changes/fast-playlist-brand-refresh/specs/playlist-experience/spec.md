# playlist-experience

## Requirement: AI mode has no redundant service tagline

Экран создания в режиме AI SHALL показывать основной заголовок и поле запроса
без текста `AI собирает плейлист`. Подпись `Поиск по каталогу` в режиме поиска
должна остаться.

### Scenario: Open AI mode

- **WHEN** пользователь открывает вкладку создания в режиме AI
- **THEN** текст `AI собирает плейлист` отсутствует в DOM
- **AND** основной заголовок и кнопка создания остаются доступны.

## Requirement: Compact halftone brand mark

Шапка Mini App и favicon SHALL использовать точечную дугу из SVG-точек,
визуально близкую к предоставленному референсу, без внешнего сетевого запроса.
Знак должен оставаться читаемым в тёмной и светлой темах.

### Scenario: Render brand mark

- **WHEN** Mini App открывает шапку
- **THEN** отображается точечная дуга вместо прежней иконки `@`
- **AND** знак не меняет размеры шапки при переключении темы.

## Requirement: Bounded playlist generation

Обычный запуск генерации SHALL завершать агентский цикл не позднее четырёх
итераций, если раньше не был вызван `finalize_playlist`. Внутри итерации
параллельный поиск и существующие кэши должны сохраняться.

### Scenario: Normal request

- **WHEN** агент сначала ищет кандидатов, а затем финализирует плейлист
- **THEN** выполняются только необходимые ходы поиска и финализации
- **AND** результат содержит найденные треки.

### Scenario: Stalled agent

- **WHEN** агент не финализирует плейлист
- **THEN** он не может бесконечно добавлять LLM-запросы сверх нового лимита
- **AND** существующий error/fallback path возвращает контролируемый результат.
