# Design: restore-miniapp-playlist-visuals

## Решения

- Оставить существующую спокойную тёмную систему и бирюзовый акцент. Bitmap
  остаётся одним фиксированным верхним слоем и не становится текстурой контента.
- Финальные правила разместить в `anti-slop.css`, который загружается после
  legacy `glass.css`; пользовательский незакоммиченный diff в `glass.css`
  сохранить без изменений.
- Краткий список плейлистов дополнить полем `coverArtworks` с максимум четырьмя
  непустыми artwork из треков этого же пользователя. Данные выбираются одним
  пакетным запросом; пустые плейлисты возвращают пустой массив. Поле additive,
  существующие клиенты его игнорируют.
- Один artwork занимает всю квадратную обложку; от двух до четырёх показываются
  мозаикой без обрезания самого контейнера. При отсутствии artwork остаётся
  нейтральная иконка.
- Варианты подписки используют явные области сетки, поверхности из текущей
  схемы и компактные значения. На узком экране CTA списка плейлистов переносится
  целой кнопкой, а не ломает текст внутри.

## Проверка

- Тест хранилища подтверждает пустой fallback, ограничение четырьмя уникальными
  artwork, порядок и изоляцию по владельцу.
- `bun run typecheck`, `bun run test` и `bun run build:miniapp`.
- Ручная проверка мобильной раскладки, вычисленных стилей и обеих схем; проверить
  доступность фонового bitmap, хедера, CTA и планов подписки.
