# Design

`GenerationStatus` сохраняет получение треков из SSE и существующие строки `TrackRow`, но визуальный статус сводится к центрированному Swirl размером 48 px. Доступное имя `Подбираю музыку` остаётся у `role=status`, чтобы индикатор без текста был понятен скринридеру. Анимацию при reduced motion отключает CSS самой библиотеки `loading-dev`.

ThoughtLine, его CSS и зависимости `motion` и Hugeicons удаляются. Dev-предпросмотр продолжает показывать пустое и заполненное состояние без API-запросов.
