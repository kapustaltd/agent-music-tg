# spinner-only-generation-loading

## Why

Строка ThoughtLine с таймером и этапами перегружает экран генерации. Пользователь попросил убрать её и оставить только загрузку.

## What Changes

- Показывать в статусе генерации только Swirl.
- Сохранить превью найденных треков и его воспроизведение.
- Удалить ThoughtLine и неиспользуемые зависимости.

## Non-goals

- Не менять API генерации, SSE-события, экран результата и dev-предпросмотр.
