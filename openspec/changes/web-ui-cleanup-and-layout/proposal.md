## Why

Текущий Mini App смешивает Telegram/mobile chrome с web-раскладкой: в шапке дублируются действия, в dock остаются декоративные подписи, а desktop prompt получает отдельную декоративную панель вместо полезного музыкального контента. На мобильном это приводит к обрезанному имени бота и перегруженной верхней панели.

## What Changes

- Упростить header и navigation: один профиль в header, icon-only поиск, без переключателя темы, без декоративной подписи источников и без профиля в tabbar.
- Убрать маркетинговые/дублирующие подписи из магазина и помощи.
- Удалить ambient/context gradients, которые ломают transition и выглядят как AI-slop; сохранить только функциональные media/progress/focus effects.
- Перестроить web create surface в музыкальную раскладку с понятным rail/main/now-playing поведением без декоративной иллюстрации.
- Сохранить Telegram/mobile touch targets, навигацию, player, API и платежную логику.

## Non-goals

- Не менять API, backend, database, auth или payments.
- Не удалять полезные тексты FAQ, действия поддержки и повторного знакомства.
- Не менять бизнес-логику player или генерации.
