## Why

Telegram должен быть только точкой входа в Mini App. Текущая реализация дублирует
функции приложения в боте через inline-кнопки, callback-меню, inline/group search и
много команд, из-за чего интерфейс Telegram расходится с Mini App и остаётся
большой поддерживаемый слой.

## What Changes

- `/start` отправляет одно сообщение с одной кнопкой `web_app`, открывающей Mini App.
- Параметры `/start` продолжают обрабатываться для атрибуции, рефералов и shared
  playlist, но shared playlist открывается через URL Mini App.
- `/stats` остаётся единственной административной командой и отвечает обычным
  текстом без inline-кнопок; доступ проверяется сервером по admin-флагу.
- Удаляется регистрация Telegram-команд, callback-меню, inline/group search,
  подписочного gate и свободного текстового роутинга.
- Служебные Telegram Stars payment updates сохраняются, потому что они нужны
  оплатам, инициированным из Mini App.

## Non-goals

- Не изменяется навигация и функциональность самого Mini App.
- Не удаляются серверные API, хранилища, генерация, поиск и платёжные маршруты,
  которыми пользуется Mini App.
- Не запускается деплой.

## Impact

- Основные изменения: `server/bot/index.ts`, `server/bot/admin-panel.ts`, bot
  routing tests и документация.
- Старые bot feature modules могут остаться в репозитории как неиспользуемый код
  для отдельного удаления; они больше не подключаются в `createBot`.
