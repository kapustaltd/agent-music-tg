# restore-generation-trace-without-glyph

## Why

В предыдущей правке вместе с декоративной иконкой случайно удалились таймер и этапы подбора. Пользователь уточнил, что нужно убрать только иконку рядом со строкой.

## What Changes

- Вернуть строку подбора с таймером и сворачиваемыми этапами.
- Не показывать декоративную иконку перед текстом ThoughtLine.
- Сохранить Swirl как единственный индикатор загрузки и превью найденных треков.

## Non-goals

- Не менять API генерации, SSE-протокол и воспроизведение треков.
