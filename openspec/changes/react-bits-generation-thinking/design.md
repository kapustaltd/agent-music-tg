# Design

ThoughtLine получает только безопасные русские названия этапов. Соседние повторы убираются, в трассе остаются последние четыре этапа. Компонент хранит локальный таймер, очищает интервал при размонтировании и уважает `prefers-reduced-motion`. Swirl остаётся декоративным, текст статуса доступен скринридеру. Превью найденных треков и их кнопки не меняются.

Dev-предпросмотр рендерится только при `import.meta.env.DEV` и переключает три фиктивных SSE-состояния. В нём не вызываются API и не нужны Telegram credentials. Production-сборка не показывает этот маршрут.

`loading-dev@0.3.4` декларирует React 19 как peer dependency, тогда как Mini App использует React 18. Проверка сборки и ручная проверка в браузере подтверждают работоспособность используемого Swirl; при будущих обновлениях React нужно перепроверить совместимость.
