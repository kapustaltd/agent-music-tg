# react-bits-generation-thinking

## Why

Во время генерации Mini App показывает обычный индикатор. Пользователь хочет видеть живую строку «thinking» с этапами работы и Swirl для загрузки.

## What Changes

- Добавить адаптацию ThoughtLine из предоставленного примера React Bits для русского интерфейса.
- Показывать этапы из существующего SSE-потока и таймер в строке thinking.
- Заменить индикатор генерации на Swirl из `loading-dev`.
- Добавить локальный dev-предпросмотр `?preview=loading` без Telegram-авторизации.

## Non-goals

- Не менять API генерации, доступ к музыке или экран результата.
- Не показывать скрытое рассуждение модели: этапы остаются публичными статусами SSE.
