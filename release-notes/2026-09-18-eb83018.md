*Автоматический деплой тестового инстанса* 🚀

- GitHub Actions проверяет typecheck, тесты и production-сборку Mini App.
- После успешных проверок push в `main` автоматически деплоит тестовый бот.
- SSH-ключ и host key хранятся в GitHub Environment `test`.
- Одновременные деплои тестового сервиса сериализуются.
